## THE PREMISE

KidiuVision is a browser-based computer-vision playground where the image itself becomes the dataset: load it, inspect its signal, transform it, and export the result.

## THE EXPERIENCE

**KidiuVision is a browser-based computer-vision playground where the image itself becomes the dataset: load it, inspect its signal, transform it, and export the result.**

## THE SYSTEM

Pixels first. Interface second. | Measure before you interpret. | Keep the image local when the product does not need a server.

## THE STACK

The MVP uses the browser Canvas 2D API for pixel sampling, luminance, RGB estimation, histogram generation and image transforms. The product is deliberately dependency-free and local-first.
